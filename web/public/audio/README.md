# Optional ambient sound

Add your own commercially licensed, looped `ambient.mp3` here (recommended ≤2 MB, about −20 LUFS). No audio is generated or downloaded by this project. Rebuild to enable the sound button. Missing audio is shown as “Sound unavailable”. Playback is off on page load; a saved ON preference resumes only after a user gesture. The last manual choice is recorded locally, not sent anywhere.
